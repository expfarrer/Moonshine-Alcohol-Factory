    /* =====================================================================
       BUCKET WEIGHTS -- container + contents          (2026-09-06 sweep)

       Engine ground truth, measured live on mvfast (not estimated):
         * Base.BucketEmpty declares Weight 1.0 and a component FluidContainer
           with Capacity 10.0, so a sink-filled vanilla bucket reads 11.
         * InventoryItem.getUnequippedWeight() = getActualWeight() +
           getContentsWeight(), and getContentsWeight() for a FluidContainer is
           literally fluidContainer.getAmount() -- the engine's own liquid
           density is exactly 1.0 kg per litre.
         * Every mash item below is a legacy base:food with NO FluidContainer,
           so the engine adds nothing for contents.  The script Weight has to BE
           the whole full weight.  Food.getActualWeight() then tapers it linearly
           down to the ReplaceOnUse item's weight (BucketEmpty = 1.0) as the
           bucket is emptied -- verified live: CornMash at Weight 10 read 10.00
           full and 5.50 half.  So this one number gives both ends for free.

       CONTENTS of a mash bucket: a full 10 L bucket of grain-and-water slurry.
       Density taken as 1.0 kg/L.  Real corn/potato mash is about 1.0-1.1; the
       rounding is deliberate so a bucket of mash reads exactly like the vanilla
       bucket of water rather than carrying an invented number.  (Conservation
       of the recipe's inputs would give only ~4.9 kg -- 15 Corn at 0.2, Sugar
       0.6, Yeast 0.2 -- but the `-fluid 0.1 [Water]` line is a documented
       water-QUALITY gate, not the real fill, and the item's icon/model are a
       full bucket.  Fill volume wins over input mass here.)

       COVERED variants add the 2.0 kg Base.Tarp that CoverCornMashBucketWith-
       Tarp really consumes:  1.0 + 10.0 + 2.0 = 13.0.  The tie is deliberately
       NOT modelled -- the recipe accepts RubberBand 0.1 / RubberHose 0.3 /
       Rope 0.8 / Wire 1.0 but produces one fixed output item, so there is no
       single honest number for it.

       Summary:   uncovered bucket of mash  11.0
                  covered   bucket of mash  13.0
       ===================================================================== */
